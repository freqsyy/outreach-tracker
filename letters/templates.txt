# Шаблоны писем Гордона.
# Формат: блок между === <id> ===. Внутри — тело письма с плейсхолдерами:
#   {greeting}  - подставится из пула приветствий (рандом)
#   {site}      - домен сайта
#   {bug}       - ЧЕЛОВЕЧЕСКИЙ вариант бага (уже переведён из технического)
#   {niche}     - ниша сайта (из tags)
#   {cta}       - вариант предложения аудита (рандом)
#   {tg}        - телеграм (ссылка/ник)
# Строка "SUBJ: ..." перед телом = тема письма (тоже поддерживает плейсхолдеры).
# Пустой {greeting} = письмо без приветствия (сразу к делу).
# Тона и длины чередуются намеренно, чтобы обойти спам-фильтры.

Вот что увидел: {bug}
Если это не закрыть, часть посетителей просто уйдёт, не оформив заказ.

{cta} — не просто «вот что не так», а «вот как сделать, чтобы заработало». Условия и цену обсудим в личке, без наездов.

Мой Telegram: {tg} — там быстрее отвечаю.
С уважением, Назар
