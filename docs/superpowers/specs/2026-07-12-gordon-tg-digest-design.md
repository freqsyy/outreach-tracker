# 📊 Гордон — Еженедельный дайджест в ТГ (Блок 2)

## Цель
Назар видит воронку Гордона прямо в Телеграме без захода на ПК/дашборд:
раз в неделю автоматически + по команде в любой момент. Цифры берутся из
`track.py stats` и топ-N горячих лидов по `score` (Блок 1).

## Архитектура
Отдельный агент `digest_bot.py` (как мост). Переиспользует готовое:
- `send_telegram.py` — отправка в ТГ;
- `bridge_poll.py` / мост `gordon-bot` — приём команды (свободный текст);
- `track.py stats` + `agent_scorer` (колонка `score`).

### Сбор цифр (`digest_bot.py`)
- `build_digest() -> str`:
  - считает статусы из `sites` (total/pending/sent/replied/hired/rejected/bounced/review);
  - конверсия `replied / sent` в %;
  - топ-5 лидов по `score DESC` (url + балл);
  - заметка про скаута (сколько `source=scout`).
- Формат: компактный текст с эмодзи (в стиле vault):
  ```
  🛡 Гордон — дайджест
  📨 Всего: 220 | pending: 78 | sent: 104 | replied: 1 | hired: 0
  ❌ rejected: 1 | 💀 bounced: 0 | 🔍 review: 5
  📈 Конверсия ответов: 0.96%
  🔥 Топ лидов: freelancespace.ru (85), clypy.app (70)...
  ```

### Авто-режим
- Крон: цепляем к существующему мосту (он уже ходит раз в час :07).
  Добавляем проверку «сегодня воскресенье (или день недели из `.env`) и ещё не
  слали на этой неделе» → шлём дайджест. Флаг «уже слал» в `digest_sent_week.txt`
  (как `bridge_done.txt`).
- Конфиг: `DIGEST_ENABLED`, `DIGEST_DOW` (дефолт 7=воскресенье), `DIGEST_HOUR`.

### По команде
- В `bridge_poll.py` детект свободного текста: «дайджест» / «digest» / «статус»
  → перенаправляет в `digest_bot.build_digest()` → ответ в ТГ сейчас.

### Обработка ошибок
- `send_telegram.py` недоступен (нет токена) → лог, не падает (как сейчас мост).
- БД пуста → «нет данных».
- `score` ещё нет (Блок 1 не сделан) → топ лидов пропускаем, не падаем.

### Тестирование
- `tests/test_digest.py`:
  - `build_digest` на мок-БД даёт ожидаемые строки статусов;
  - конверсия считается верно (защита от деления на 0 при sent=0);
  - отсутствие `score` не ломает сборку.

## План реализации (коротко)
1. `digest_bot.py` + `build_digest`.
2. Хук в `bridge_poll.py` (детект команды) + авто-крон (флаг недели).
3. Конфиг в `.env` (DIGEST_*).
4. Тесты.

## Связи
- Опирается на Блок 1 (колонка `score`).
- Зависит от рабочего моста ПК<->ТГ (уже собран 2026-07-10).
